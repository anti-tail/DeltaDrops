## スクリプトがやってくれること

このスクリプトは，入力された言語データをもとに，以下の処理を自動でおこないます．

1. あらかじめ作成した各地点の借用耐性のある言語形質の形質行列を比較し，地点間の系統的距離を計算します．
2. 緯度・経度の情報から，隣り合う地点同士のネットワーク（Delaunay 網）を作成します．
3. 2 によって定義された，地理的に隣接し，かつ言語的に似ている地点を，貪欲法というアルゴリズムによって少しずつまとめていきます．このまとまりの妥当性の評価には，系統ネットワークの樹状構造からの逸脱の度合を測る δ スコアという指標を用いています．
4. 最終的に出来上がった言語群を，ボロノイ図として色分けして出力します．

それ以上のことはしてくれないので，あとは出力されたログなり折れ線グラフなりを解釈して，自力でなんとかしてください．
## 必要な準備
### 0. 借用耐性のある形質による形質行列の作成
あなたの知識と持っているデータに基づいて，形質行列を作成してください．

### 1. ソフトウェアのインストール
本スクリプトを実行するには，統計解析ソフト R と，操作画面を使いやすくする RStudio が必要です．インストールされていない場合は，あらかじめご準備ください．

### 2. 必要なRパッケージのインストール
初回実行時のみ，以下のパッケージ群をインストールする必要があります．Rのコンソール画面に以下のコードを貼り付けて実行（Enter）してください．

```R
install.packages(c("tidyverse", "sf", "deldir", "igraph", "geosphere", "ggrepel", "mapdata"))
```

## データの準備とフォルダ構成

手元のパソコンに任意のフォルダを作成し，以下のようなフォルダ構成にしてください．

```text
project_folder/
  ├─ README.md                <-- この説明書
  ├─ src/
  │   └─ delta_score_optimizer.R  <-- 本スクリプト
  ├─ data/
  │   └─ hogehoge.txt            <-- 分析したい言語データ（入力ファイル）
  └─ output/                  <-- 分析結果がここに保存されます（最初は空のフォルダで OK）

```

### 入力データの形式

入力データは，タブ区切りのテキストファイル（TSV形式）で用意します．Excelなどでデータを作成し，「タブ区切りテキスト」として保存してください．
一行目には，以下の名前の3つの列が**必須**です．大文字小文字に注意してください．

* `Taxon`: 地点名や変種名（例：松山市，AA語BB変種など）
* `Lat`: その地点の緯度（10進数，例：33.839）
* `Long`: その地点の経度（10進数，例：132.765）

上記の列に続けて，各言語形質のデータを列として追加します．こちらはどんな名前でもよいです．ただし見出しは一行でないとコードが実行できないので注意してください．

## 実行方法

1. RStudioで `src/delta_score_optimizer.R` を開きます．
2. スクリプト全体のコードを選択し，実行（Run）します．
（※あらかじめ本リポジトリの構成通りにファイルを配置していれば，パスの書き換え等をしなくてもそのまま動くように設計されています）

## 出力されるファイル

解析が完了すると，`output` フォルダに以下の3つのファイルが自動で生成されます．

1. `hogehoge_Voronoi_map.png`
* 分析結果を地図上に落とし込んだものです．同じ色で塗られた地域が，1つの変種群とみなされた範囲です．変種群同士の境界地域は赤系，どこにも属さなかった孤立地点はグレーで表示されます．


2. `hogehoge_trajectory_plot.png`
* 変種群がどのように変種を吸収して大きくなっていったか，またその際のδスコアがどのように推移したかを示す折れ線グラフです．


3. `hogehoge_history.csv`
* どの順番で地点が変種群に追加されたか，詳細な数値が記録されたデータ表です．論文を執筆するときの結果の検証に利用できます．
